# TsGym-Chat Android 5.0.0

نسخه رسمی WebView امن برای `https://tsgym.ir/panel/tsgymchat_app/`.

ویژگی‌ها:

- نام رسمی `TsGym-Chat` و خروجی `TsgymChat.apk`
- لوگوی شفاف روی پس‌زمینه سفید
- بدون نوار بارگذاری افقی بالای صفحه
- حفظ کامل اصلاح SSL Certum
- HTTPS-only و محدودسازی دامنه‌ها
- شناسه دستگاه با Cookie امن HttpOnly سمت سرور
- بررسی نسخه قبل از ورود
- دانلود با نوار پیشرفت
- بررسی SHA-256، Package و امضای APK پیش از نصب
- FileProvider امن برای بازکردن Installer
- میکروفن فقط برای دامنه مجاز
- Release امضاشده با کلید دائمی

راهنمای ساخت و انتشار: `RELEASE-GUIDE-FA.md`
